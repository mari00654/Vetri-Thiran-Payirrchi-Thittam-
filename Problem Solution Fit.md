## Problem - Solution Fit
The Problem-Solution Fit confirms that the solution actually solves the customer's problem.

| Canvas Element | Description |
| --- | --- |
| **Customer Segment** | Service desk agents, incident managers, ServiceNow administrators |
| **Problem** | Incidents are saved with missing or inconsistent data (no assignee/group, wrong urgency) and State is changed from lists without checks |
| **Jobs-to-be-done / Pains** | Log incidents quickly and correctly; avoid rework, mis-routing and SLA breaches |
| **Triggers** | High-impact outage reported; SLA reviews show poor data quality |
| **Emotions (before / after)** | Before: rushed, anxious, frustrated. After: confident, guided, in control |
| **Available Solutions** | Manual checks, training, post-save business rules, reports |
| **Our Solution** | Client-side UI Policy + Client Scripts that enforce rules at entry time |
| **Behaviour / Channels** | Online: ServiceNow Incident form and list views |
| **Why it fits** | Rules fire instantly while the user is working, so errors are prevented rather than corrected later |

**Purpose:** solve the problem in a way that fits how agents already work, increase adoption by staying inside the existing form, and improve data quality at the point of entry.

## Proposed Solution

| S.No. | Parameter | Description |
| --- | --- | --- |
| 1 | Problem Statement (Problem to be solved) | Incident records are often submitted with incomplete or inconsistent data, affecting triage, routing, reporting and SLA compliance |
| 2 | Idea / Solution description | Use a UI Policy (*High Impact Control*) with actions on Assignment group and Urgency, plus three Client Scripts (onChange, onSubmit, onCellEdit) to enforce rules on the Incident form and list |
| 3 | Novelty / Uniqueness | Combines declarative UI Policies with targeted client scripts; fully reversible behaviour (*Reverse if false*); no server-side code or licences needed |
| 4 | Social Impact / Customer Satisfaction | Faster resolution, fewer bounced tickets and more reliable service for end users; less frustration for agents |
| 5 | Business Model (Revenue Model) | Internal IT efficiency: lower rework cost and fewer SLA penalties; reusable as a configuration package for other ServiceNow customers |
| 6 | Scalability of the Solution | Extend to more fields, priorities, tables (Problem, Change) or convert to an update set for easy promotion across instances |

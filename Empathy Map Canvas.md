## Empathy Map Canvas
An empathy map captures what a user says, thinks, does and feels, so the team can design around real needs. Here the primary user is a **Service Desk Agent / Incident Caller** who creates and updates Incident records in ServiceNow.

| Quadrant | Observations |
| --- | --- |
| **Says** | "I forgot to assign this high-impact incident." · "Why is this ticket missing the assignment group?" · "Which urgency should I pick for this impact?" |
| **Thinks** | "I want to log incidents quickly." · "I hope I filled in everything needed for routing." · "Reports will be wrong if data is inconsistent." |
| **Does** | Creates incidents from calls/emails · Picks Impact and Urgency manually · Edits State directly in the list view to save time · Saves records with optional fields left blank |
| **Feels** | Rushed during busy hours · Anxious about SLA breaches · Frustrated when tickets bounce back for missing data |

| Pains | Gains |
| --- | --- |
| Incomplete or inconsistent records · Wrong urgency for high-impact issues · Accidental state changes from list edits · Rework and SLA misses | Clear guidance on what is required · Automatic, consistent field values · Fewer bounced tickets · Accurate reporting and faster resolution |
